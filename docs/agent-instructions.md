# Agent Instructions: Brand

## Read this first

**The single source of truth is `docs/design.md`.** Read it in full before producing any brand-facing output. It contains everything: colour tokens, typography, buttons, interactive elements, logo (including inline SVG), spacing, imagery, iconography, brand modes, voice, and writing style.

Previous files (`visual-identity.md`, `brand-application-rules.md`, `voice-and-tone.md`, `writing-style-guide.md`) have been consolidated into `design.md` and archived in `docs/_archive/`.

## The golden rules

1. **The brand is law, not suggestion.** These rules are constraints to follow. If it says "never", it means never.
2. **Assets come from the canonical set.** Never recreate, approximate, or source brand assets from outside the repo. If an asset doesn't exist, flag a gap.
3. **Voice is as binding as visual identity.** A feature that looks right but reads wrong is not brand-correct.
4. **Context changes the register, not the identity.** Marketing copy and error messages sound different — but both are unmistakably Nivoda.
5. **When in doubt, don't improvise.** Flag a gap. Wait for a ruling from Chris.

## Before producing any brand-facing output

1. Read `docs/design.md` in full
2. Identify the mode: editorial or UI (§10 — Brand modes)
3. Apply the vocabulary for that mode
4. Only then produce output

## If you encounter a gap

1. Stop immediately
2. Do not improvise a brand decision
3. Output: "BRAND GAP DETECTED: [describe what is missing and in which context]"
4. Wait for instruction before continuing
