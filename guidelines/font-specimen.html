The colour rules

On dark backgrounds

  • No violet. Ever. Violet on dark looks bad.
  • Buttons: soft dark fill (stone-800) → white on hover
  • Links: secondary text → white on hover
  • Card borders: subtle (stone-700) → lighter on hover
  • The palette is black, white, and stone tones only

On light backgrounds

  • Violet appears here — only on hover
  • Buttons: dark fill → violet on hover
  • Links: muted text → violet on hover
  • Card borders: light grey → violet on hover
  • Violet is never a resting state — it's always earned by interaction
The principle: Violet is precious. It only appears where there's light (white/light surfaces) and only when the user reaches for something (hover). On dark surfaces, the interaction language is black → white. Violet against dark is banned.
